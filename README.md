# Autoescola Bandeirantes — site institucional
Site estático (HTML/CSS/JS), sem build. Fotos otimizadas em `assets/`.

**Edite `main.js` (topo do arquivo):** telefone, WhatsApp, endereço, horário, Instagram e depoimentos.
Enquanto o WhatsApp estiver vazio, os botões ligam para o telefone. Use `showPlaceholders:false` quando concluir.
Publicação: GitHub Pages → branch `main` / raiz.
